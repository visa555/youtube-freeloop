# English Grammar ม.ต้น

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html`, `app.js`, `style.css` | หน้าเว็บ หน้าสรุปเนื้อหา และระบบทำแบบฝึกหัด ใช้ร่วมกันทุกเรื่อง |
| `data/topics.json` | หมวด รายชื่อเรื่องทั้งหมด และจำนวนข้อต่อรอบ (`questionsPerRound`) |
| `data/topics/<id>.json` | สรุปเนื้อหา (`lesson`) และคลังข้อสอบ (`questions`) ของแต่ละเรื่อง |

ลำดับการใช้งาน: `#/` เลือกเรื่อง → `#/<id>` อ่านสรุป → `#/<id>/quiz` ทำแบบฝึกหัด
แต่ละรอบสุ่มข้อจากคลังตาม `questionsPerRound` คะแนนสูงสุดเก็บใน localStorage ของเครื่องผู้เรียน

## เพิ่มเรื่องใหม่

1. ดู `id` ของเรื่องใน `data/topics.json` เช่น `present-continuous`
2. สร้างไฟล์ `data/topics/present-continuous.json` ตามรูปแบบด้านล่าง (คลังข้อสอบควรมี 40–60 ข้อ)
3. ใส่ `"ready": true` ให้เรื่องนั้นใน `data/topics.json` เรื่องที่ยังไม่มีจะแสดงเป็น "เร็ว ๆ นี้"
4. ตรวจไฟล์ด้วย `python tools/validate.py` (สคริปต์อยู่ในโฟลเดอร์ `firebase-project/grammar`)

## รูปแบบไฟล์เรื่อง

```json
{
  "lesson": {
    "summary": "ประโยคสรุปสั้น ๆ ว่าเรื่องนี้คืออะไร",
    "sections": [
      {
        "icon": "🧱",
        "title": "โครงสร้าง",
        "text": "ย่อหน้าอธิบาย (หรือรายการย่อหน้า)",
        "formulas": [{ "label": "บอกเล่า", "formula": "S + **V1**", "example": "She **plays** tennis." }],
        "table": { "head": ["หัวคอลัมน์", "..."], "rows": [["ช่อง", "..."]] },
        "chips": ["yesterday", "last night"],
        "list": ["ข้อ 1", "ข้อ 2"],
        "examples": [{ "en": "I **went** home.", "th": "ฉันกลับบ้าน" }],
        "mistakes": [{ "wrong": "He **go**.", "right": "He **goes**.", "why": "เหตุผล" }]
      }
    ],
    "tip": "เคล็ดลับจำง่าย ๆ"
  },
  "questions": [
    {
      "q": "เติมคำในช่องว่าง: She ___ to school every day.",
      "options": ["go", "goes", "going", "gone"],
      "answer": 1,
      "explanation": "คำอธิบายเฉลย"
    }
  ]
}
```

- หัวข้อใน `sections` ใส่เฉพาะส่วนที่ต้องใช้ และจะแสดง **ตามลำดับที่เขียนในไฟล์**
- ครอบคำด้วย `**คำ**` เพื่อไฮไลต์ ใช้ได้ทั้งในสรุป คำถาม ตัวเลือก และคำอธิบาย (ถ้าไฮไลต์ในตัวเลือก ให้ไฮไลต์ทุกตัวเลือก จะได้ไม่เป็นการบอกใบ้)
- `answer` คือลำดับตัวเลือกที่ถูก **เริ่มนับจาก 0** (A = 0, B = 1, C = 2, D = 3)
- ระบบสลับตำแหน่งตัวเลือกทุกครั้ง ใส่ `"keepOrder": true` ในข้อที่ต้องคงลำดับ เช่น Type 0 / 1 / 2 / 3
- ห้ามใช้เครื่องหมาย `"` ในข้อความ ให้ใช้ “ ” แทน
