# ฝึกทำข้อสอบเข้า ม.1

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html`, `app.js`, `style.css` | หน้าเว็บและระบบทำข้อสอบ ใช้ร่วมกันทุกวิชา |
| `data/subjects.json` | วิชา เรื่อง จำนวนข้อต่อชุด (`draw`) จำนวนข้อที่วางแผนไว้ในคลัง (`bank`) และจำนวนชุด (`sets`) |
| `data/<วิชา>/<เรื่อง>.json` | ข้อสอบของแต่ละเรื่อง (คลังข้อสอบ) |
| `data/<วิชา>/sets.json` | ชุดข้อสอบ: ข้อที่อยู่ในชุด ลำดับข้อ และลำดับตัวเลือกของแต่ละข้อ |
| `data/img/<id ข้อ>.svg` | รูปประกอบโจทย์ (ถ้ามี) |
| `PLAN.md` | แผนงานและผังข้อสอบทั้ง 5 วิชา |

ลำดับการใช้งาน: `#/` เลือกวิชา → `#/<วิชา>` เลือกชุด → `#/<วิชา>/<ชุด>/practice` (ฝึกทำ ตรวจทีละข้อ) หรือ `#/<วิชา>/<ชุด>/exam` (จำลองสอบ จับเวลา ส่งทีเดียว)

ข้อสอบเป็นชุดตายตัว ชุดละ 40 ข้อ ทำซ้ำได้ชุดเดิมทุกครั้ง ทุกชุดแบ่งจำนวนข้อของแต่ละเรื่องตาม `draw` = `[ง่าย, ปานกลาง, ยาก]` และเรียงจากง่ายไปยาก
วิชาจะเปิดให้ทำเมื่อ `subjects.json` มี `"sets"` แล้ว (ระหว่างที่ยังไม่มี จะแสดงว่า “กำลังจัดทำข้อสอบ”)
คะแนนสูงสุด ล่าสุด และจำนวนครั้งที่ทำของแต่ละชุด รวมทั้งประวัติ 10 ครั้งล่าสุด เก็บใน localStorage ของเครื่องผู้เรียน (`onet-sets`)

## เพิ่มเรื่องใหม่

1. ดู `id` ของวิชาและเรื่องใน `data/subjects.json` เช่น วิชา `math` เรื่อง `numbers` และดูจำนวนข้อที่ต้องเขียนจาก `bank` เช่น `[4, 8, 3]`
2. สร้างไฟล์ `data/math/numbers.json` ตามรูปแบบด้านล่าง
3. ใส่ `"ready": true` ให้เรื่องนั้นใน `data/subjects.json`
4. ตรวจไฟล์ด้วย `python tools/validate.py` (สคริปต์อยู่ในโฟลเดอร์ `firebase-project/onet`) สคริปต์จะบอกด้วยว่าแต่ละเรื่องเขียนครบตาม `bank` แล้วหรือยัง
5. เมื่อเขียนครบทุกเรื่องของวิชาแล้ว ให้สร้างชุดข้อสอบตามหัวข้อถัดไป

## สร้างชุดข้อสอบ

รันในโฟลเดอร์ `firebase-project/onet`:

```
python tools/build_sets.py math
```

- สร้าง `data/math/sets.json` และใส่ `"sets": 4` ให้วิชาใน `subjects.json` (คลัง 160 ข้อ ÷ 40 ข้อต่อชุด = 4 ชุด เพราะ `bank` ของทุกเรื่องเท่ากับ 4 เท่าของ `draw` พอดี ทุกข้อจึงอยู่ในชุดใดชุดหนึ่งและไม่มีข้อซ้ำกันระหว่างชุด ถ้าคลังไม่ลงตัวพอดี จะมีบางข้อซ้ำกันระหว่างชุด)
- ทุกชุดมีจำนวนข้อต่อเรื่องตาม `draw` และมีง่าย-ปานกลาง-ยากเท่ากันทุกชุด
- กำหนดลำดับตัวเลือกตายตัวและกระจายคำตอบที่ถูกให้เป็น ก ข ค ง ใกล้เคียงกัน
- รันซ้ำได้ผลเดิมทุกครั้ง เปลี่ยนจำนวนชุดได้ด้วย `--sets 4` และได้ชุดแบบอื่นด้วย `--seed 2`
- สคริปต์ไม่สร้างทับ `sets.json` ที่มีอยู่แล้ว เพราะคะแนนของผู้เรียนผูกกับเลขชุด ถ้าแก้คลังข้อสอบ (เพิ่ม/ลบข้อ) แล้วต้องการจัดชุดใหม่จริง ๆ ให้ใส่ `--force`
- แก้ไขเนื้อหาข้อสอบ (คำถาม คำอธิบาย ตัวลวง) ได้โดยไม่ต้องสร้างชุดใหม่ ตราบใดที่ไม่เปลี่ยน `id` จำนวนตัวเลือก หรือ `level`

## รูปแบบไฟล์ข้อสอบ

```json
[
  {
    "id": "math-numbers-01",
    "level": 2,
    "q": "คำถาม",
    "options": ["ตัวเลือก ก", "ตัวเลือก ข", "ตัวเลือก ค", "ตัวเลือก ง"],
    "answer": 0,
    "explanation": "วิธีคิดทีละขั้น และเหตุผลที่ตัวลวงผิด"
  }
]
```

- `id` ตั้งเป็น `<วิชา>-<เรื่อง>-<เลขข้อ 2 หลัก>` ห้ามซ้ำ และห้ามเปลี่ยนหลังสร้างชุดข้อสอบแล้ว (`sets.json` อ้างถึงข้อด้วย `id`)
- `level` 1 = ง่าย, 2 = ปานกลาง, 3 = ยาก (ระดับสอบเข้าห้องเรียน EP) ดูความหมายแต่ละระดับใน `PLAN.md`
- `answer` คือลำดับตัวเลือกที่ถูก **เริ่มนับจาก 0** (ก = 0, ข = 1, ค = 2, ง = 3) ตำแหน่งตัวเลือกในชุดข้อสอบกำหนดโดย `build_sets.py` จึงใส่คำตอบไว้ตำแหน่งไหนก็ได้
- ใส่ `"keepOrder": true` ในข้อที่ต้องคงลำดับตัวเลือก เช่น มีตัวเลือก “ถูกทุกข้อ” (`build_sets.py` จะไม่สลับตัวเลือกของข้อนี้)
- `explanation` ต้องมีทุกข้อ
- ข้อที่มีรูป: ใส่ `"image": "img/<id>.svg"` และ `"imageAlt": "คำอธิบายรูป"` วาดรูปบนพื้นขาว ขนาดประมาณ 360 × 220
- ครอบคำด้วย `**คำ**` เพื่อไฮไลต์ (ถ้าไฮไลต์ในตัวเลือก ให้ไฮไลต์ทุกตัวเลือก จะได้ไม่เป็นการบอกใบ้)
- ห้ามใช้เครื่องหมาย `"` ในข้อความ ให้ใช้ “ ” แทน
- ภาษาอังกฤษแสดงตัวเลือกเป็น A B C D (ตั้งค่า `"letters": "ABCD"` ไว้ที่วิชาใน `subjects.json`)
