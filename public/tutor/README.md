# แบบทดสอบ ป.6

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html`, `quiz.js`, `style.css` | หน้าเว็บและระบบทำข้อสอบ ใช้ร่วมกันทุกวิชา |
| `data/subjects.json` | รายชื่อวิชาและเรื่องทั้งหมด |
| `data/<วิชา>/<เรื่อง>.json` | ข้อสอบของแต่ละเรื่อง |

## เพิ่มข้อสอบเรื่องใหม่

1. ดู `id` ของวิชาและเรื่องใน `data/subjects.json` เช่น วิชา `math` เรื่อง `fractions`
2. สร้างไฟล์ `data/math/fractions.json` ตามรูปแบบด้านล่าง
3. ใน `data/subjects.json` เพิ่ม `"ready": true` ให้เรื่องนั้น เรื่องที่ยังไม่มี `ready` จะแสดงเป็น "เร็ว ๆ นี้"

เพิ่มเรื่องหรือวิชาใหม่ได้โดยเพิ่มรายการใน `subjects.json` (`id` ใช้ภาษาอังกฤษตัวเล็กและ `-` เท่านั้น เพราะใช้เป็นชื่อไฟล์และ URL)

## รูปแบบไฟล์ข้อสอบ

```json
[
  {
    "id": 1,
    "q": "คำถาม",
    "options": ["ตัวเลือก ก", "ตัวเลือก ข", "ตัวเลือก ค", "ตัวเลือก ง"],
    "answer": 0,
    "explanation": "คำอธิบายเฉลย"
  }
]
```

- `answer` คือลำดับตัวเลือกที่ถูก **เริ่มนับจาก 0** (ก = 0, ข = 1, ค = 2, ง = 3)
- ระบบสลับตำแหน่งตัวเลือกทุกครั้งที่เริ่มทำ ใส่ `"keepOrder": true` ในข้อที่ต้องการคงลำดับไว้ เช่น ข้อที่มีตัวเลือก "ถูกทุกข้อ"
- `explanation` ไม่บังคับ ถ้าไม่ใส่ ระบบจะแสดงคำตอบที่ถูกแทน
- ถ้าไฟล์ผิดรูปแบบ หน้าเว็บจะแจ้งว่าผิดที่ข้อไหน
